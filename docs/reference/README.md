# 참고 자료 (docs/reference)

노션은 게스트가 볼 수 없어서, 개발에 필요한 노션 내용을 이 폴더에 정리했다.
AI(Claude Code, Codex)와 팀원 모두 이 폴더를 기준 자료로 읽는다.

## 파일 목록
| 파일 | 내용 | 우선순위 |
|---|---|---|
| [DECISIONS.md](DECISIONS.md) | 지금 기준의 최종 확정 사항, 미확정 항목, 자료 간 충돌 정리 | 1 |
| [WORK_ASSIGNMENT.md](WORK_ASSIGNMENT.md) | 11/23 업무 분배 (담당별 1차·2차 업무, 연결 내용, 완료 기준) | 2 |
| [MEETING_NOTES.md](MEETING_NOTES.md) | 11/19, 11/23 회의록 정리 (결정 과정과 근거) | 3 |

자료끼리 내용이 다르면 **번호가 작은 파일이 우선**한다.
(`PRD.md`, `TECH_SPEC.md`, `WORK_UNITS.md`는 이 폴더보다 먼저 쓰인 초안이라 이 폴더보다 오래된 내용이 있을 수 있다.)

## 주의
- 회의 녹음(클로바노트)은 아직 이 폴더에 없다. 녹음 텍스트가 정리되면 `DECISIONS.md`를 보정한다.
- 이 저장소는 Public이다. 이 폴더에는 키, 비밀번호, 개인정보를 넣지 않는다.
- 내용이 틀렸거나 바뀌었다면 팀장에게 알리고, 팀 합의 후 이 폴더를 고친다.
