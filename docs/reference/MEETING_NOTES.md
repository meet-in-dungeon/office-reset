## 11/19(목) 1일차

### 아이데이션 및 주제 선정
- 제외 주제: 온라인 게임 개발, 물류 유통
- 나온 후보: 실버 케어, 반려동물 통역기, 갱년기, 쇼핑몰, 회의록 자동화, 보이스피싱 판별, 약봉투 복약 알림, IoT 지팡이, 거북목 교정, 행사 관리 등
- 선택 기준: 실용성(문제 해결 시나리오), 데모에서 눈에 띄는 UI와 난이도, 지금 테스트 가능한 또래 타겟, 만들면서 재미있을 것
- 키워드: 일상 리셋, 리커버리, 회복. "아픈 거 스트레칭 맨날 까먹는다 → 사무실에서 몰래 할 수 있는 스트레칭"
- 초기 컨셉: "3분 리셋"(몸도 마음도 리셋). 이름은 확정이 아니다.

### 결정 사항
| # | 결정 | 내용 |
|---|---|---|
| 1 | 주제 | 운동 분야 — 스트레칭 + 명상(호흡) 결합 서비스 |
| 2 | 컨셉 | 지친 몸과 마음을 되돌리는 "리셋/회복" (서비스명은 추후 확정) |
| 3 | 타겟 | 30~50대 직장인. 실버는 보류 |
| 4 | 앱 성격 | 발표용 앱. 스토리텔링, 수업 기술 활용, 과정 기록이 평가 포인트 |
| 5 | 원칙 | 실용성 필수, 입력 최소화, 눈에 띄는 UI, 배운 기술 활용 |
| 6 | 명상 위치 | 별도 앱처럼 분리하지 않고 스트레칭 흐름에 녹임 |
| 7 | 플랫폼 | 모바일 느낌 중심 웹, PC에서는 좁지 않게 확장 (무신사 방식 참고) |
| 8 | 소리 | 소리 켜기·끄기 설정 필수, 소리 없이도 사용 가능 |

### 문제 정의 (5개 합의)
- 업무에 몰입하면 목과 어깨가 아픔
- 스트레칭을 안 해서 통증이 생김
- 건강하려고 운동·스트레칭하다 오히려 다침
- 시간 내기 아깝고 귀찮음
- 핵심 방향: 가볍게 원하는 사람보다 "억지로라도 스트레칭하게 만드는" 쪽 (예: "허리 수술 3천만 원 아끼려면 지금 허리 펴라")
- 출근하면 이 사이트부터 켜놓는 습관, 타이머와 리워드(예: 50분이 지나면 알림, 완료하면 리워드), 일주일 단위 꾸준함 경쟁, 현업 운동 코치가 만든 사이트라는 신뢰
- "전문가" 표현은 신중히. 의료가 아닌 참고용 문구를 쓴다.

### 경쟁 서비스 조사 요약
| 서비스 유형 | 참고할 점 | 판단 |
|---|---|---|
| 마이슬로우바디(스트레칭+호흡) | 3D 캐릭터, 음악, 타이머, 부위 선택 시 동작 8개, 시간 끝나면 자동 전환, 전문가 시연 영상 | 우리가 생각한 것과 가장 가까움. 선택지는 간결하게(최대 3개) |
| 웹 스트레칭 서비스(Wakeout) | 웹, 알림, 음악 on/off, 다음 동작 넘기기, 게임화 | 웹 방향 참고 1순위 |
| 직장인 스트레칭(Stiff) | 알림, XP, 배지, 일일 미션, 순위표 | 리워드·랭킹은 장점, 동작은 사진이라 단점 |
| Bend, Stretchly | 일러스트 스트레칭, 휴식 알림, 연기·건너뛰기 | 동작에 움직임을 주면 좋음 |
| 호흡·명상 앱(Calm, Headspace, 마보, 코끼리, 숨모라, Breathwrk 등) | 차분한 UI, 호흡 시각화(원·꽃이 커졌다 작아짐), 기분별 사운드, 7일 챌린지, 첫 화면에서 "왜 왔는지" 질문 | 명상·호흡 화면 참고용. 입장 즉시 소리가 나면 사무실에서 곤란 |
| 웹캠 자세 인식(BaroSit) | 스켈레톤 표시 | 인식이 부정확, 회사 PC에 카메라가 없을 수 있음 → 이후 MVP 제외됨 |
| 자세 교정 앱(Postima) | 온보딩 질문(아픈 부위, 나이, 직업, 자세 슬라이더, "하루 5분이면 충분합니다") | 온보딩 참고 |

### 3차 회의 합의
- 온보딩에 부위·직업·자세 질문과 "하루 24시간 중 5분" 같은 문구를 넣자는 의견
- 소리: 사무실에서 갑자기 소리가 나면 곤란 → 켜기·끄기 설정 필요, 소리 없이도 사용 가능
- 캐릭터: 동작을 보여주는 캐릭터가 중요, 3D가 보기 편했다는 의견 (사람 vs 캐릭터는 당시 미확정 → 11/23에 3D 캐릭터로 확정)
- 해창님 안내(과정 요구사항): EXAONE API 사용과 결과 스트리밍 안내가 있었다. 필수 여부는 확인 필요.

## 11/23(월) 2일차 — 서비스 상세 기획 및 개발 범위 확정

### 서비스 기획 논의
- 타깃 정리: 사무실에서 근무하는 직장인 / 출근 후~퇴근 전, 업무 중 / 사무실 / 스트레칭·호흡 운동 / 웹·앱 서비스
- 알림: 팝업·인앱 알림 논의. 기본 주기는 1시간. "알림은 하루 몇 번 울리는 게 좋으신가요?" 질문으로 세팅하고 "보통 사람들은 1시간 주기로 합니다."를 안내하는 아이디어
- 간편함: 알림을 누르면 스트레칭으로 연결, 클릭 수 최소화, 메인 화면은 누구나 바로 쓰게 (어린이 게임처럼)
- 안내 방식: 영상(그림), 음성, 동작 이름(중요도 낮음), 설명 / 소리 온오프, 볼륨 조절
- 습관 형성 아이디어: 랭킹, 닉네임, 개인 목표 칭찬, 캐릭터·정원 꾸미기, 칭호, 배지 → 결과적으로 **주간 랭킹은 제외, 배지로 대체**
- 웹캠·AI 동작 인식: 취소선 처리(제외)
- 참고 아이디어: 업무 중 알림 연기(미루기), 처음 세팅 간소화, 즉시 회복 루틴 시작 → MVP 제외

### 사용자 플로우 초안
최초 접속(소개·온보딩) → 메인 화면(상태·목표·업무 시작) → 업무 진행(타이머·휴식 안내) → 회복 루틴 시작(알림·스트레칭) → 호흡 및 스트레칭(동작 안내·시간 측정) → 루틴 완료(기록·보상·성취감) → 업무 복귀(타이머 재시작)

### 콘텐츠 결정
- 표현 방식: 실제 사람 / AI 실사 영상 / **3D 캐릭터** / 2D 일러스트 중 **C(3D 캐릭터) 확정**. 사무복 착용, 앉은 자세, 책상 있어야 함. 실사 영상(A)은 현실적으로 제외.
  - 의견: 원규 "이미지도 나쁘지 않음(멈추는 구간)", 진수 "3D가 따라하기 좋음, 간단한 동작은 이미지가 나을 수 있음", 주연 "B or C"
- 부위: 상반신 위주 — 목, 어깨, 손목, 허리 (+호흡, 명상). 부위별 3개씩 정해놓고 전달.
- 상황: 앉아서만 진행
- 동작 시간: 5초 (토큰 줄이기)
- 난이도 구분: 취소선(제외)
- 주의 안내: 통증이 느껴지면 중단하세요. 전문가와 상의하세요. 천천히 충분히 호흡하면서 움직여 주세요.
- 데이터 확보: 전문가 유튜브 참고, 원규 님 보유 도서 참고. 소수의 동작으로 자체 데이터 목록을 만든다.
- 데이터 항목 결정: 동작명 / 대상 부위(목·어깨·손목·허리) / 이용 상황(사무실에서 앉아서) / 소요 시간(회당 5초) / 동작 설명(음성·텍스트, "고개 돌리세요 카운트 5~1") / 호흡 안내(페이지 분리 구성) / 주의 사항(통증 시 중단) / 가이드 자료(3D 캐릭터 영상, 음성, BGM, 텍스트) / 참고 출처(전문가 유튜브, 원규 님 도서)
- 마이슬로우바디 참고: 음악·타이머가 좋음, 랜덤으로 동작을 다르게 전달하면 재방문 이유가 생김(결정 아님)

### 배지 규칙 설계 (후보, 일부 확정)
- 출석 / 루틴 완성(루틴: 네 가지 스트레칭 완료) / 명상 1분·5분 달성(시간별) / 빡침 해소 배지 / 마음의 평화·바디 건강(명상)
- 이후 업무 분배에서 1차 배지 3종: 첫 루틴, 하루 완성, 첫 빡침 해소

### 기술 검증 (PoC) 결과 메모
- 스트레칭 콘텐츠 조사 (김원규): 12개 동작 후보표를 산출물로 한다.
- 배지 규칙 설계 (이주연): AI를 활용해 설계. 하루 완성 배지 조건은 "스트레칭 루틴 및 호흡 5회 완료".
- 3D 캐릭터 제작 검증 (서진수): 사무복·책상 3D 캐릭터와 대표 동작 1개 영상 제작 완료, 웹 재생 테스트 완료. 3시간에 3~4개 영상 생성 가능.
- 타이머·브라우저 알림 검증 (김민지): 알림 권한 요청, 다른 탭 사용 중 알림, 브라우저별 차이와 제한 사항 확인, 어려울 때 대체 방안 검토. 결과물은 `poc/timer-notification` 브랜치의 PoC와 `docs/POC_TIMER_NOTIFICATION.md` 참고.
- GitHub 협업 환경 준비 (김민지): 조직 저장소 생성, 팀원 초대, 브랜치·PR 규칙 수립.

### 시연·예외 처리 아이디어
- 평가자가 핵심 기능을 빠르게 체험할 수 있는 시연 모드 검토
- 예외 상황: 알림 권한 거부, 인터넷 오류 등 대응 필요

### 디자인
- 필요 화면은 간단한 와이어프레임을 두고 논의 (결정 사항 칸은 비어 있음)
- UI 레퍼런스: 명상 앱·스트레칭 앱 디자인(민지 님 아이디어 덤프), 개인 통계 화면 이미지 참고
