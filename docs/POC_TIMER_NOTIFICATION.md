# 타이머·브라우저 알림 PoC 테스트 안내 (Windows / macOS)

기술 검증용 임시 페이지입니다. 실제 서비스 화면이 아닙니다.
범위: 브라우저 탭이 열려 있는 상태의 알림. **브라우저를 완전히 종료한 상태의 푸시 알림은 검증하지 않습니다.**

## 접속 방법

### A. 웹 링크 (배포 URL이 공유된 경우)
공유받은 `https://.../poc.html` 주소를 Chrome에서 엽니다. 설치가 필요 없습니다.
알림 기능은 HTTPS 또는 localhost에서만 동작합니다.

### B. 내 컴퓨터에서 실행 (Windows)
1. Git, Node.js 24 이상(LTS) 설치 (README 1번 참고)
2. PowerShell 또는 터미널에서:
   ```bash
   git clone https://github.com/meet-in-dungeon/office-reset.git
   cd office-reset
   git checkout poc/timer-notification
   npm install
   npm run dev
   ```
3. Chrome 주소창에 `http://localhost:5173/poc.html` 입력
   (터미널에 다른 포트가 나오면 그 포트를 사용). 서버를 끄면 접속이 안 되므로 터미널 창은 열어 둡니다.

## Windows 사전 설정 (알림이 안 보일 때 확인)

1. **Chrome 사이트 권한**: 페이지 주소창 왼쪽 아이콘 → 사이트 설정 → 알림 → "허용". 이미 "차단"했다면 여기서 바꾸고 새로고침.
2. **Windows 알림 켜기**: 설정 → 시스템 → 알림 → 알림 켜짐, 목록에서 **Google Chrome** 켜짐.
3. **방해 금지 / 집중 지원 끄기**
   - Windows 11: 설정 → 시스템 → 알림 → "방해 금지" 끄기 (작업 표시줄 오른쪽 알림 센터에서도 가능)
   - Windows 10: 설정 → 시스템 → 집중 지원 → "끔"
   - 게임/발표/전체 화면 앱 사용 중에는 자동으로 켜질 수 있음
4. 알림은 몇 초 뒤 사라지고 **알림 센터(Win+N)** 로 이동합니다. 사라졌다면 알림 센터를 확인하고, 이 경우도 기록해 주세요.

## 테스트 순서

1. `알림 권한 요청` → 팝업에서 "허용" → 현재 권한이 `granted`인지 확인
2. `즉시 테스트 알림` → 알림이 뜨는지 확인
3. `10초 테스트` 선택 → `시작` → 탭을 그대로 두고 알림 확인
4. 다시 `시작` → **다른 Chrome 탭**으로 이동해 10초 대기 → 알림 확인
5. 다시 `시작` → Chrome을 두고 **다른 프로그램**(메모장, 카카오톡 등) 사용 → 알림 확인
6. 4·5번에서 뜬 알림을 **클릭** → Chrome과 PoC 탭으로 돌아오는지 확인
7. (선택) `1분 테스트`로 4번을 한 번 더
8. 권한 거부 테스트: Chrome 사이트 설정에서 알림을 "차단" → 새로고침 → 빨간 안내 문구와, 타이머 종료 시 화면 내 "타이머가 끝났습니다!" 표시 확인
9. 페이지 하단 **로그**에서 `탭 상태: hidden`으로 알림이 발생했는지 확인 (다른 탭/프로그램 테스트가 실제로 숨김 상태였는지 증거가 됩니다)

## 알려진 한계
- 브라우저 종료 상태 알림 불가 (서비스 워커 + 푸시 서버 필요, 이번 범위 아님)
- 방해 금지/집중 지원, 전체 화면 앱 사용 중에는 OS가 알림을 숨길 수 있음
- 알림 클릭 시 `window.focus()`가 다른 앱 위로 Chrome을 가져오는지는 OS 정책에 따라 다를 수 있음
- 숨겨진 탭에서는 타이머 호출이 늦어질 수 있어 종료 시각 기준으로 계산하지만, 장시간 타이머는 별도 검증 필요
